# 3. Comentarios

Los comentarios son notas explicativas que el compilador de Java ignora por
completo y no son relevantes para la ejecuci&oacute;n.

```java
// Single line comment

/* Multiline
   comment in
   several lines */
```

Además, existe una convención para hacer documentación en código con comentarios:

```java
/**
* This function executes a sum of two numbers
* and yadda yadda yadda.
*
* Some more lines of description.
*
* @param  a a number
* @param  b another number
* @return the sum of both numbers
*/
int sum(int a, int b);
```
