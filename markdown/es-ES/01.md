# Taller de Introducci&oacute;n al Lenguaje de Programaci&oacute;n Java

## 1.1 Convenci&oacute;n de nombres y tipos primitivos

En Java, la mayor parte de nombres se escriben, por convenci&oacute;n, con la
notaci&oacute;n **camelCase**. Son excepciones los nombres de clases, que usan
**PascalCase**, y las constantes, que usan **SCREAMING_SNAKE_CASE**.

Java es un lenguaje tipado, por lo que toda declaraci&oacute;n deber&aacute; ir
obligatoriamente acompa&ntilde;ada de su tipo.

Los tipos primitivos son los m&aacute;s sencillos de este lenguaje. Los
m&aacute;s usados son: `int`, para n&uacute;meros enteros, `double`, para
n&uacute;meros reales, `char`, para caracteres individuales, y `boolean`, para
valores l&oacute;gicos (V/F).

## 1.2 Declaraci&oacute;n de variables

Las variables se declaran siguiendo el formato `<type> <name>;` y se le pueden
asignar valores con el formato `<name> = <value>;`.

La declaraci&oacute;n y asignaci&oacute;n conjunta es posible con: `<type>
<name> = <value>;`.

```java
int edadEstudiante = 20;              // N&uacute;meros enteros
double precioMatricula = 450.50;      // N&uacute;meros reales
char calificacion = 'A';              // Un solo car&aacute;cter
boolean haAprobado = true;            // Valores l&oacute;gicos (true / false)
final String NUMERO_DNI = "03628172"; // Cadena de caracteres

int numeroPokemons;                   // Declaraci&oacute;n
numeroPokemons = 151;                 // Asignaci&oacute;n posterior
int pokemonSeleccionado = 4;          // Ambas en una sola sentencia
```

Nota: `final` indica que una variable no podr&aacute; cambiar de valor,
esencialmente haciendo que esta no sea variable, sino constante.
