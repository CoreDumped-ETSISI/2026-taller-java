## 10. Herencia y Polimorfismo en Java

La **herencia** y el **polimorfismo** son dos de los cuatro pilares fundamentales de la Programación Orientada a Objetos (POO). Juntos permiten reutilizar código, establecer jerarquías lógicas y diseñar aplicaciones flexibles y escalables.

---

### 10.1 Herencia (`extends`)

La herencia es un mecanismo que permite a una clase (llamada **clase hija**, subclase o derivada) heredar los atributos y métodos de otra clase (llamada **clase padre**, superclase o base). 

#### Características principales:
* Se utiliza la palabra reservada `extends` para indicar que una clase hereda de otra.
* Promueve la **reutilización de código**: el código común se escribe una sola vez en la clase padre.
* En Java, una clase solo puede tener **un único padre directo** (no existe herencia múltiple de clases para evitar la ambigüedad).
* Se puede acceder a los miembros de la clase padre mediante la palabra reservada `super`.

#### Ejemplo práctico:

```java
// Parent Class (Superclass)
public class Animal {
    protected String name;
    protected int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void eat() {
        System.out.println(name + " is eating: *Chomp chomp, wait, is that a stapler?*");
    }
}

// Child Class (Subclass) inheriting from Animal
public class Dog extends Animal {
    private String breed;

    public Dog(String name, int age, String breed) {
        super(name, age); // Calls the parent class constructor
        this.breed = breed;
    }

    public void bark() {
        System.out.println(name + " is barking: *Meow? I mean... Quack quack!*");
    }
}
```

### 10.2 Polimorfismo

El polimorfismo significa literalmente "muchas formas". En Java, es la capacidad de que un mismo método o mensaje se comporte de manera diferente según el objeto sobre el cual se esté aplicando. Permite tratar a los objetos de las clases hijas como objetos de la clase padre.

Existen dos tipos principales de polimorfismo:
1. **Polimorfismo en tiempo de compilación (Sobrecarga / Overloading):** Múltiples métodos con el mismo nombre pero diferentes parámetros dentro de la misma clase.
2. **Polimorfismo en tiempo de ejecución (Sobrescritura / Overriding):** Una clase hija redefine un método heredado de su clase padre usando la anotación `@Override`.

#### Ejemplo práctico:

```java
// Superclass with a base method
public class MusicalInstrument {
    public void play() {
        System.out.println("Playing a generic instrument: *Dial-up modem connecting noise*");
    }
}

// Subclass 1
public class Guitar extends MusicalInstrument {
    @Override
    public void play() {
        System.out.println("Strumming the guitar: *BEEP BEEP BEEP... The microwave is done!*");
    }
}

// Subclass 2
public class Piano extends MusicalInstrument {
    @Override
    public void play() {
        System.out.println("Playing the piano keys: *MOOOOOOOO!*");
    }
}

// Using polymorphism
public class Main {
    public static void main(String[] args) {
        // A parent class reference can point to child class objects
        MusicalInstrument myInstrument1 = new Guitar();
        MusicalInstrument myInstrument2 = new Piano();

        myInstrument1.play(); // Output: Strumming the guitar: *BEEP BEEP BEEP... The microwave is done!*
        myInstrument2.play(); // Output: Playing the piano keys: *MOOOOOOOO!*
    }
}

```

---

### 10.3 Resumen

> * **Herencia:** Permite construir nuevas clases basadas en clases ya existentes, jerarquizando el código (relación *"es un"*).
> * **Polimorfismo:** Permite escribir código genérico que puede operar con diferentes tipos de objetos de manera uniforme, facilitando enormemente el mantenimiento y la extensibilidad del software.
